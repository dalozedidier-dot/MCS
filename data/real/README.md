# Données réelles

Ce dossier n'est jamais rempli avec des données inventées. Les fichiers sont téléchargés depuis les sources officielles ou enregistrés localement avec leur empreinte SHA-256.

Les données volumineuses et leurs archives ne doivent pas être commitées. Conserver uniquement les fichiers `provenance.json`, les protocoles gelés et les résultats agrégés autorisés par les licences.
