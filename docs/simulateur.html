Ce simulateur exécute le même modèle que le dépôt Python : le moteur JavaScript (mcs-engine.js) est vérifié en intégration continue contre le moteur de référence, trajectoire par trajectoire, à 10−9 près (tests/test_js_parity.py). Ce n'est pas une illustration : c'est le modèle.

Garde-fous de lecture (§9.8). M(t) est un indice ordinal, rapporté ici avec son incertitude : aucune valeur isolée ne constitue un diagnostic. Les seuils de zones sont des hypothèses pédagogiques à calibrer par domaine. Les proxys L, R, B doivent être définis avant tout calcul (protocole gelé, §9.2). Et le modèle contient sa propre mise en garde : trop de contrôle dégrade les boucles qu'il prétend restaurer (§6.3). Cadre exploratoire — ni diagnostic clinique, ni outil managérial validé.
