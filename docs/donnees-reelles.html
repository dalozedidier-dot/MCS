Validation sur données réelles

Aucun résultat empirique n’est prérempli. Cette page distingue strictement les mesures réelles des simulations. Les résultats ne seront publiés qu’après téléchargement des sources officielles, calcul reproductible, contrôle d’intégrité et validation temporelle.

Sources installées dans la chaîne

Principe de preuve

Chaque téléchargement produit un provenance.json contenant URL officielle, date, taille et SHA-256 de chaque fichier. Les données brutes ne sont jamais modifiées. Les séparations apprentissage/validation doivent être temporelles et les événements doivent provenir des annotations externes du jeu de données.

Commandes

pip install -e ".[real,viz]"
python scripts/fetch_real_data.py --list
python scripts/fetch_real_data.py metropt3
python scripts/fetch_real_data.py hydraulic
python scripts/fetch_real_data.py ims_bearings
